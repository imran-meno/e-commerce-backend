# E-Commerce Application — Backend

Node.js/Express REST API powering the e-commerce frontend. Handles authentication, product management, cart, and order logic with MongoDB.

## 🔗 Links
- **Frontend Repo:** https://github.com/imran-meno/e-commerce-frontend

## ✨ Features
- JWT-based authentication and authorization
- OAuth integration (Google, Facebook, GitHub)
- Product, cart, and order management endpoints
- MongoDB data models with Mongoose
- File upload support
- Deployed on Vercel

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT
- Passport.js (OAuth)

## 🚀 Getting Started
```bash
npm install
node index.js
```

Create a `.env` file with:
```
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```
